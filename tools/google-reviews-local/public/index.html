Collega il profilo Google Business

L’accesso a Google nel browser non collega automaticamente questa pagina. Serve un’autorizzazione API del proprietario o gestore della sede.

  1. Abilita l’accesso alle API Google Business Profile nel progetto Google Cloud.
  2. Configura l’autorizzazione OAuth per il profilo che gestisce Buenos Aires.
  3. Imposta sul server locale le credenziali e l’identificativo della sede, poi riavvia la pagina.

La configurazione tecnica è descritta nel README del progetto. Le credenziali non vengono inserite nelle recensioni.
